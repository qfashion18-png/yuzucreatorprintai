# AI Agent Design

The AI package exposes `AiDesignAssistant` with mock and Bedrock implementations. MVP actions include:

- Make this merch-ready.
- Create sticker ideas.
- Match my brand vibe.
- Write flyer/postcard copy.
- Add QR CTA.
- Recommend a creator launch kit.
- Explain print issues in plain English.

Bedrock Runtime model IDs and Guardrail IDs are environment driven. Local mode uses deterministic mock responses.
